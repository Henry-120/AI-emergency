# 全體強震演練

首頁保留所有使用者都能操作的「🚨 模擬強震」，沿用本機地震通知、避難流程與附近 BLE 存活訊號測試，不呼叫全體推播 API。下述「🧪 全體強震演練」是郭碩宏帳號額外可用的獨立按鈕。

「🧪 全體強震演練」向所有已註冊的推播裝置發送「非真實地震」通知，不會啟動真實地震回報或 BLE 求救流程。原生 App 前景收到通知、或使用者點開背景通知時，會在對話中顯示該次演練內容。

## 使用權限

必須線上登入後端唯一帳號「郭碩宏」。前端透過 `GET /api/earthquake/drill/permission` 決定是否顯示按鈕；`POST /api/earthquake/drill` 再次驗證登入憑證，並比對後端帳號索引中的使用者 ID。未登入回傳 401，其他帳號回傳 403。離線本機同名帳號無法發送。

後端必須設定非預設的 `AUTH_SECRET`；使用開發預設值或範例值時，本功能回傳 503。請使用私密隨機值，勿提交到版本控制。變更金鑰後，既有使用者需重新登入。

## 上線與驗證

部署後端並更新接收端 App，完成 Firebase 推播設定、裝置 token 註冊及通知授權。郭碩宏重新線上登入後即可使用按鈕。舊版 App 仍可能收到通知橫幅，但需更新才能在對話中顯示演練資料。

以郭碩宏發送一次演練，分別檢查另一台裝置在前景與背景點擊的結果；使用其他帳號確認按鈕隱藏且 API 拒絕請求。這會真的向所有註冊裝置發送演練，請在預定演練時操作。

畫面回報的成功數代表推播服務接受，不代表裝置已收到或已讀。無有效 token、未允許通知或無網路的裝置不保證收到；網頁版尚未實作遠端推播接收。發送中按鈕會停用，伺服器出錯時可能已有部分裝置收到，避免立即重送。

自動驗證：`python3.13 -m unittest discover -s backend/tests -v`、`npx tsc --noEmit`、`npm run build`。
